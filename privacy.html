Privacy policy

Last updated: 2 November 2026

This policy covers the Hmm.verse uploader, a private tool that publishes Hmm.verse's own videos to Hmm.verse's own YouTube channel. It is not offered to the public and no one else signs in to it.

What data the uploader uses

  • Google account access: the Hmm.verse channel owner authorises the uploader once with Google OAuth, using the YouTube scopes needed to upload videos and post a comment on them (youtube.upload, youtube.force-ssl). The resulting token is stored only as an encrypted secret in the private build system that runs the uploader, and is used only to act on the Hmm.verse channel.
  • Video content: the uploader sends Hmm.verse's own video files, titles, descriptions and one comment to YouTube.

What it does not do

  • It does not collect, read, store, sell or share personal data of any viewer or any other YouTube user.
  • It does not use cookies, analytics or tracking.
  • It does not access any account other than the Hmm.verse channel.

Google API services

The uploader uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions or through Google's security settings page. When access is revoked, the stored token stops working and is deleted from the build system. The uploader keeps no other data.
